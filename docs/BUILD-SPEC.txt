3. Stack Decision
Recommendation: port to Next.js 15 (App Router) now, in Phase 0.
 
Do it while the codebase is ten components,
not sixty.
3.1 Why
This is a catalogue business. Its entire acquisition funnel is Google and Meta ads landing on category and product URLs. A
Vite SPA ships an empty 
<div id="root">
 and renders everything client-side; product titles, prices, and structured data arrive
after JavaScript executes. That is the single most expensive mistake to discover late — it is exactly the issue flagged in the
Al-Madina Jewellers audit. Next.js gives server-rendered product pages, per-route metadata, ISR for price/stock freshness,
and 
next/image
 responsive handling without extra plumbing.
The port is cheap right now because Tailwind classes, shadcn/ui components, and React presentational components move
across almost unchanged. Only three things actually change: routing (file-based), image handling, and metadata.

# Khawaja Collection (KC) — Project Memory
## What this is
Premium Pakistani fashion e-commerce storefront. Mobile-first.
UX benchmark: LAAM. NEVER copy LAAM's assets, copy, colours, or markup.
## Stack
Next.js 15 App Router / TypeScript (strict) / Tailwind / shadcn-ui /
Zustand (cart + wishlist) / Supabase (Phase 5+) / Vercel.
## Commands
npm run dev # local dev
npm run build # must pass before any commit
npm run lint
npx tsc --noEmit # must be clean
## Hard rules
1. No product data inside components. Everything via src/lib/repositories/*.
2. Every page exports `metadata` or `generateMetadata`. No exceptions.
3. Product and category pages are Server Components. Interactivity lives in
 small "use client" leaf components only.
4. Prices are integers in PKR. No floats. Format with formatPKR().
5. Use design tokens (CSS variables). No arbitrary hex values in JSX.
6. Every image uses next/image with width, height, sizes, and alt.
7. No new dependency without asking first.
8. Mobile layout is designed separately, not scaled down from desktop.
9 . Do not invent social media URLs, phone numbers, addresses, or prices.
 Use PLACEHOLDER constants in src/config/site.ts.
10. Run `npm run build` before telling me a phase is done.
## Style
- Components: PascalCase files in src/components/<domain>/
- Hooks: use*.ts in src/hooks/
- Types: src/types/index.ts — single source of truth
- Prefer composition over props explosion. Max ~7 props per component.
## Definition of done for any task
TypeScript clean, build passes, responsive at 360 / 768 / 1024 / 1440,
keyboard navigable, no console errors, no layout shift on image load.
